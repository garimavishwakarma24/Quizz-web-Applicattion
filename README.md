#Quiz Web Application
A responsive and interactive quiz application built using HTML, CSS, and JavaScript. This project tests users on programming and computer science fundamentals with dynamic question rendering, real-time feedback, and a built-in timer.

✨ Features
🚀 Start screen with name input and personalized greeting
❓ Multiple-choice questions with navigation (Next, Previous)
⏱️ Real-time timer to track how long users take to complete the quiz
📝 Displays final score along with time taken and review of incorrect answers
🎨 Clean and modern UI with Flexbox layout, gradients, and subtle shadows

🛠 Tech Stack
HTML – Structure and layout
CSS – Responsive and visually appealing design
JavaScript – Logic for quiz flow, timer, and user interaction
